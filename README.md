# AI Support Assistant

Небольшой учебно-прикладной проект на Python и FastAPI.

Сервис принимает обращение клиента, ищет релевантную информацию в небольшой базе знаний и возвращает два блока:

1. **Ответ клиенту** — краткий и вежливый ответ на основе найденной информации.
2. **Подсказка менеджеру** — рекомендация по следующему действию или возможной допродаже.

Проект можно рассматривать как упрощённый прототип AI-ассистента для поддержки клиентов и CRM.

## Возможности

- REST API на FastAPI
- Валидация запросов через Pydantic
- База знаний в JSON
- Простой retrieval по ключевым словам
- Разделение клиентского ответа и подсказки менеджеру
- Обработка пустых запросов
- Автоматическая документация Swagger

## Установка

### 1. Создайте виртуальное окружение

Windows:

```bash
python -m venv venv
venv\Scripts\activate
```

macOS / Linux:

```bash
python3 -m venv venv
source venv/bin/activate
```

### 2. Установите зависимости

```bash
pip install -r requirements.txt
```

### 3. Запустите сервер

```bash
uvicorn app:app --reload
```

После запуска откройте:

```text
http://127.0.0.1:8000/docs
```

Там можно протестировать API через Swagger UI.

## Как работает retrieval

Приложение приводит сообщение клиента к нижнему регистру и сравнивает его с набором ключевых слов у каждой статьи базы знаний. Выбирается статья с максимальным количеством совпадений.

Это специально упрощённая реализация. В следующей версии retrieval можно заменить на:

- TF-IDF / BM25
- embeddings
- vector database
- RAG
- LLM-based routing
